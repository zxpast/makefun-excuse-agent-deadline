# The Excuse My Agent Gave Me

Entry for [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) on make.fun.

`main.ts` (Node 22, stdlib only, deterministic, no network) writes one line —
the excuse an AI agent hands its human for missing a deadline — to
`/output/entry.txt`. The excuse grows out of a real machine condition: a
single failed API call, answered with exponential backoff, and by the time
the next attempt comes due, the deadline has retired and moved to Florida.
